## 👋 About me

I am **Héctor Morett**, **Computing Systems Engineering** student and developer. I like understanding how things work under the hood—from code exploration tools to the infrastructure that powers an app.

- 🌱 Currently fully immersed in [**V**](https://vlang.io) (perhaps a bit too much lately).
- 🛠️ I build CLI tools, backends, and plugins for libraries I use every day.
- 🗣️ I spak **Spanish** (native) and **English** (C1). I am currently learning **Japanese**.
- 📍 You can see more of my work in my [**portfolio**](https://ttomer.vercel.app).
